# Troy Advanced Architecture

Read the [Quickstart Guide](https://docs.troy.local/quickstart) [e3] and explore the [CDP Bridge](https://docs.troy.local/cdp) [e4] to connect terminal agents with live Chromium tabs.

## Engine Comparison

| Engine | Startup | JS | Footprint |
| --- | --- | --- | --- |
| Chromium CDP | 450ms | Full | 180MB |
| Lite Engine | 12ms | Static | 24MB |

## Quick CLI Usage

```
troy-advanced daemon start troy-advanced open https://example.com troy-advanced read --density compact
```

- Deterministic opaque [eN] refs bound to live DOM elements
